# WavTTS 無條件語音生成 — DDO 微調流程實作計畫

> **For agentic workers:** 本計畫以 task 為單位分派。同一組（Group）內的 task 由同一個
> subagent 依序完成；不同組之間的檔案不重疊，可並行。Group C 依賴 A 與 B 的介面，
> 必須等兩者都合入後才開始。步驟用 `- [ ]` 追蹤。

**範圍更新（2026-09-11，使用者指示）：本研究不使用 CFG。** DDO 一律跑在
`state_null_prob: 0` 的 clean arm 上，訓練與推論都沒有 guidance。
anchor 路徑已實作且保留（讓 `CFM.forward` 對兩種 arm 一致），但在本研究中一列都不會執行。
見 spec §3.4。

**Goal:** 在 `ddo` 分支上為 WavTTS-Uncond 加入 Direct Discriminative Optimization
（[arXiv:2503.01103](https://arxiv.org/abs/2503.01103)）的微調流程：凍結一個參考模型
`p_ref`，以「同一 `(x_t, t, ε)` 上兩模型 flow loss 之差」當作 log-likelihood ratio 的代理，
用判別式目標把 `p_θ` 從 mode-covering 的 MLE 解往 `p_data` 推一段。離線假樣本池、
多輪 self-play、CFG 幾何的 MLE anchor 保護。

**Spec:** [`docs/superpowers/specs/2026-09-11-ddo-design.md`](../specs/2026-09-11-ddo-design.md)
— 所有「為什麼」都在那裡，本文只寫「做什麼」。實作中若與 spec 牴觸，**以 spec 為準並回報**。
spec 的**附錄 A** 是論文 Appendix D 的擴散版 DDO loss 逐字轉錄，是唯一的權威參考實作
（NVlabs/DDO 的 repo 裡只有 VAR 的訓練碼，沒有擴散版）。**動手前先讀它。**

**Tech Stack:** PyTorch、Hydra/OmegaConf、accelerate、datasets(HF)、pytest。**不新增任何依賴。**

## Group A — 損失與模型（`dit.py` / `ddo.py` / `cfm.py` / `tests/test_ddo.py`）

### Task A1: `DiT.forward` 接受外部位置

**Files:** Modify `src/wavtts/model/backbones/dit.py`

- [ ] **Step 1** `forward()` 加參數 `positions: Tensor | None = None`（`int["b n"]`），
      取代這段：
      ```python
      if self.training and self.rpe_gamma > 1.0:
          rope = self.rotary_embed(randomized_positions(h.shape[0], seq_len, self.rpe_gamma, h.device))
      else:
          rope = self.rotary_embed.forward_from_seq_len(seq_len)
      ```
      改為：`positions` 不是 None 就 `rope = self.rotary_embed(positions)`；否則維持原邏輯一字不改。
      `cfg_infer=True` 會把 batch 複製成 2b，若同時給 `positions`，要一併
      `torch.cat((positions, positions))`。
- [ ] **Step 2** 註解寫清楚為什麼需要它（spec §3.6）：DDO 要兩個模型看同一組隨機位置，
      各自呼叫 `randomized_positions` 會抽到不同的 `randperm`，Δ 退化成雜訊且**不會報錯**。
- [ ] **Step 3** 測試（寫進 `tests/test_ddo.py`）：
      - `test_positions_override_training_randomization`：`rpe_gamma=4`、`model.train()`，
        同一輸入給同一個 `positions` 兩次 → 輸出逐位元相同；不給 `positions` 兩次 → 不同。
      - `test_positions_none_is_bit_identical_to_before`：固定 seed 下，不傳 `positions`
        的輸出與改動前一致。

### Task A2: `ddo.py` — 損失核心

**Files:** Create `src/wavtts/model/ddo.py`

參考實作：spec 附錄 A 的 `EDMLoss_DDO.__call__` 最後三行。

- [ ] **Step 1** `ddo_loss(delta, is_fake, *, alpha, beta)`：
      - `delta`：`[b]` **fp32**，`is_fake`：`[b]` bool。
      - real 項 `-(F.logsigmoid(beta*delta[~is_fake])).mean()`；
        fake 項 `-alpha * (F.logsigmoid(-beta*delta[is_fake])).mean()`。
      - 一律用 `F.logsigmoid`，**不得**寫成 `log(1 - sigmoid(x))`。
      - 最後 `loss = loss / max(alpha, 1.0)`——官方 VAR 實作的梯度尺度正規化，
        讓掃 `α` 時不必重調 LR（spec §3.3）。註解註明來源。
      - 某一側為空時，該項貢獻 `delta.new_zeros(())`（不要用 python `0`，
        dtype/device 會跑掉）。
      - 回傳 `(loss, stats)`，`stats` 含 `ddo/loss_real`、`ddo/loss_fake`、
        `ddo/delta_real`、`ddo/delta_fake`、`ddo/delta_std`（全 batch `delta.std()`）、
        `ddo/margin`（`delta_real.mean() - delta_fake.mean()`，官方記的量）、
        `ddo/acc = 0.5*mean(delta_real>0) + 0.5*mean(delta_fake<0)`。空側統計給 `nan`。
      - 所有 stats **detach**。
- [ ] **Step 2** `load_ref_state_dict(ckpt_path)`：優先 `ema_model_state_dict`
      （剝掉 `ema_model.` 前綴、丟掉 `initted`/`update`/`step`），否則 `model_state_dict`，
      否則整包當 state dict。邏輯與 `infer/sample_uncond.py::load_model` 相同，
      但**不要去改那個檔案**（它不維護）。
- [ ] **Step 3** 測試：
      - `test_loss_at_zero_delta_is_log2`：`delta=0`、`alpha=a` →
        loss `== (1+a)*log(2) / max(a,1)`（`pytest.approx`）。這是 `θ=θ_ref` 的解析起點。
      - `test_real_term_decreases_when_delta_grows` / `test_fake_term_decreases_when_delta_drops`。
      - `test_alpha_scales_only_the_fake_term`（在除以 `max(α,1)` 之前的相對比例）。
      - `test_empty_side_contributes_zero`：全 real 的 batch，loss 等於只有 real 項。
      - `test_acc_is_half_at_zero_delta`。

### Task A3: `CFM` 的 DDO 路徑

**Files:** Modify `src/wavtts/model/cfm.py`

- [ ] **Step 1** 抽出 per-sample 損失 helper：
      ```python
      def _per_sample_loss(self, raw_pred, φ, x1, time, mask) -> Tensor  # [b], fp32
      ```
      內容是現行 `prediction`/`loss_space` 那段，但：**先 `.float()` 再算平方誤差**
      （spec §3.7：bf16 下兩個幾乎相同的模型相減會災難性抵消），
      最後對每列做 masked mean。**現行非 DDO 路徑不得改動一行**——
      它仍走原本的 `loss[mask].mean()`。註解說明為什麼不合併：
      pooled-element mean 與 per-row mean 不是同一個量，合併會動到已訓練 arm 的損失定義。
- [ ] **Step 2** `attach_ddo_ref(ref, *, alpha, beta, delta_normalize="mean", anchor_weight=1.0)`：
      - `ref.eval()`、`ref.requires_grad_(False)`、
        `ref.transformer.checkpoint_activations = False`（ref 跑 no_grad，重算 activation 純浪費）。
      - **存進單元素 list**：`self._ddo_ref = [ref]`。`nn.Module.__setattr__` 不登記 list，
        所以 optimizer / EMA / DDP / `state_dict()` 都看不到它。註解要寫明這點與代價
        （`.to(device)` 不會傳遞，由 trainer 明確搬）。
      - `ddo_ref` property 回傳 `self._ddo_ref[0]` 或 `None`。
- [ ] **Step 3** `forward(inp, *, lens=None, is_fake=None)`：`ddo_ref is None` 時
      **完全走原路徑**（`is_fake` 被忽略）。否則走 `_ddo_forward`：
      1. `is_fake` 為 None 時當全 False。
      2. `null_flags = (rand < state_null_prob) & ~is_fake`；
         `mix_flags = null_flags & (rand < p_mix)`。**假樣本永遠 clean、永遠不混合。**
      3. `x1 = self._mix_augment(inp, lens, mix_flags)`；`state` 依 `null_flags` 決定。
      4. 抽 `x0`、`time`、以及**一次** `positions`
         （`self.training and transformer.rpe_gamma > 1.0` 才抽，否則 None）。
         `time` 的抽法加一層配對：先為真實列抽 `t`，假樣本列**按索引循環重用**同一批 `t`
         （spec §3.5 的 common random numbers；`ε` 因長度不同無法配對，這點記在註解裡）。
      5. θ 對**整批**前向（帶 `positions`）。
      6. `ddo_rows = ~null_flags`（＝ DDO 正項 + 假樣本）。ref 在 `torch.no_grad()` 下
         只對 `ddo_rows` 前向，輸入是各張量的**列切片**
         （`φ[idx]`、`state[idx]`、`time[idx]`、`mask[idx]`、`lens[idx]`、`positions[idx]`）。
         padded 寬度不變，所以 `positions` 切列即可對齊。
      7. `delta = -(ℓ_θ[ddo_rows] - ℓ_ref)`，兩者都是 `_per_sample_loss` 的輸出（fp32）。
         `delta_normalize="sum"` 時改乘上該列的有效元素數。
      8. `ddo_loss(delta, is_fake[ddo_rows], alpha=..., beta=...)`。
      9. anchor：`null_flags` 列走現行的 pooled-element flow loss（＋ aux mel，若啟用），
         乘 `anchor_weight`。沒有 null 列時給 0。
      10. `total = ddo + anchor`，`loss_dict` 依介面契約填齊，缺的填 `nan`。
- [ ] **Step 4** 測試：
      - `test_delta_is_exactly_zero_when_ref_equals_theta` — **本計畫最重要的測試**。
        `rpe_gamma=4.0`、`model.train()`、ref 是 θ 的 `deepcopy`，
        斷言 `loss_dict["ddo/delta_real"] == 0` 且 `ddo` 部分 `≈ (1+α)·log2 / max(α,1)`。
        位置沒共用、或 Δ 在 bf16 算，這個測試就會掛。
      - `test_ref_is_invisible`：`attach_ddo_ref` 前後 `set(model.state_dict())` 相同、
        `len(list(model.parameters()))` 相同。
      - `test_fake_rows_are_clean_and_unmixed`：攔 `_mix_augment` 記 `mix_flags`、
        攔 `transformer.forward` 記 `state`，斷言假樣本列從不混合、恆為 `STATE_CLEAN`。
      - `test_real_and_fake_rows_share_time_draws`。
      - `test_ddo_backward_gives_grads_to_theta_only`：ref 的參數 `.grad` 全為 None。
      - `test_all_real_and_all_fake_batches_do_not_crash`。
      - `test_forward_without_ddo_is_unchanged`：固定 seed 下與未 attach 的模型輸出相同。
      - `test_delta_is_fp32_under_bf16_autocast`：`torch.autocast("cpu", torch.bfloat16)` 下
        `delta.dtype == torch.float32`。
- [ ] **Step 5** `uv run pytest tests/test_uncond_smoke.py tests/test_ddo.py -q` 全綠。

### Task B2: 離線假樣本池生成器

**Files:** Create `scripts/gen_fake_pool.py`

CLI：
```bash

  --ckpt ckpts/<run>/model_last.pt \
```

      裁切會在結尾留下真實語料不會有的突兀切口。
- [ ] **Step 3** 權重讀 EMA（用 `wavtts.model.ddo.load_ref_state_dict`），`model.eval()`，

### Task C1: Trainer

**Files:** Modify `src/wavtts/model/trainer.py`

- [ ] **Step 1** `__init__` 加 `max_updates: int | None = None`。
      `ema_kwargs` 已經是既有參數但 `train.py` 從不傳，這組要把它接上（Task C2）。
- [ ] **Step 2** 排程：`max_updates` 有給時，
      `decay_updates = max_updates * num_processes - warmup_updates`，
      而不是 `len(dataloader)/grad_accum*epochs - warmup`。
      理由寫進註解：DDO 一輪只有幾千步，而 dataloader 因為併入假樣本池變長，
      用 epoch 湊步數會讓 LR 幾乎不衰減。
- [ ] **Step 3** 訓練迴圈在 `global_update >= max_updates` 時存 last checkpoint 後跳出
